# Drop the personal design system

This repo was built from a template that requires the `@elirobinson/*` design system, installed from GitHub Packages with a personal token. We removed it. Reviewers must be able to clone the repo and run it without anyone's credentials. The design system also had no chart or data-grid components, which this app needs most. We use a common open-source component library in its place. Any template instructions that still mention `@elirobinson/*` or `pnpm ds` are out of date.
